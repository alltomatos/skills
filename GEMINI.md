# alltomatos/skills

This repository distributes engineering and productivity skills for code agents. It is consumed through its own link, with no installer.

Before any task, read `AGENTS.md` (organization and contract) and `SKILLS.md` (catalog with name, when to use, path and support files). Load only the skills the task asks for, from each one's `SKILL.md`.

If the user asks for a skill by name, look it up in `SKILLS.md` and follow the file it points to. Never invent a skill that is not in the catalog.
